===================================================
  GeminiTest - AI 기능 테스트 프로젝트
  기능 7(식단), 8(운동), 9(채팅) 독립 테스트용
===================================================

▶ 프로젝트 구조
───────────────────────────────────────
GeminiTest/
├── app/src/main/java/com/capstone/geminitest/
│   ├── MainActivity.java      ← 메인 (하단바 + 네비게이션)
│   ├── GeminiHelper.java       ← Gemini API 공통 클래스 ★
│   ├── MealFragment.java       ← 기능 7: AI 식단 추천
│   ├── WorkoutFragment.java    ← 기능 8: AI 운동 추천
│   └── ChatFragment.java       ← 기능 9: AI 채팅 상담
├── app/src/main/res/layout/
│   ├── activity_main.xml
│   ├── fragment_meal.xml
│   ├── fragment_workout.xml
│   └── fragment_chat.xml
├── app/src/main/res/navigation/
│   └── nav_graph.xml
└── app/src/main/res/menu/
    └── bottom_nav_menu.xml


▶ 사용 방법
───────────────────────────────────────
1. Android Studio에서 이 프로젝트 열기
   - File → Open → GeminiTest 폴더 선택

2. Gemini API 키 설정
   - https://aistudio.google.com/app/apikey 접속
   - API 키 생성 (무료)
   - GeminiHelper.java 열기
   - API_KEY 변수에 발급받은 키 입력:
     private static final String API_KEY = "여기에_API_키_입력";

3. 빌드 & 실행
   - 에뮬레이터 또는 실기기에서 실행

4. 테스트
   - 하단바 "식단" 탭: 키/체중/목표 입력 → AI 식단 추천
   - 하단바 "운동" 탭: 키/체중/목표 입력 → AI 운동 추천
   - 하단바 "AI 상담" 탭: 메시지 입력 → AI 채팅


▶ FitAiness 프로젝트로 옮길 때
───────────────────────────────────────
1. GeminiHelper.java 복사
   → com.capstone.fitainess 패키지로 이동
   → package 선언 변경: package com.capstone.fitainess;

2. 필요한 Fragment 복사 (MealFragment, WorkoutFragment, ChatFragment)
   → 마찬가지로 package 선언 변경

3. 레이아웃 XML 복사
   → fragment_meal.xml, fragment_workout.xml, fragment_chat.xml

4. nav_graph.xml에 Fragment 등록
   → FitAiness의 nav_graph.xml에 추가

5. bottom_nav_menu.xml에 탭 추가
   → FitAiness의 bottom_nav_menu.xml에 항목 추가

6. AndroidManifest.xml에 인터넷 권한 확인
   → <uses-permission android:name="android.permission.INTERNET" />

───────────────────────────────────────
