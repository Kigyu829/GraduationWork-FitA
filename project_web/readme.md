<테스트 구동 방식>

※ 공통
- 브라우저 localStorage에 데이터가 저장됨
- 초기화가 필요할 경우 개발자도구 > Application > Local Storage > Clear

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[랜딩, sc101]
- 최초 접속 화면
- 상단 메뉴 클릭 시 해당 섹션으로 스크롤 이동 확인
- '무료로 시작하기' 클릭 시 sc201_2(회원가입)로 이동
- '로그인' 버튼 클릭 시 sc201_1(로그인)으로 이동
- 하단 푸터 링크(이용약관, 개인정보처리방침, 공지사항, 문의하기) 클릭 확인

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[로그인, sc201_1]
테스트 계정
  아이디: test1@test.com  /  비밀번호: test1TEST
  전화번호: 010-1234-5678  /  비밀번호: test1TEST  (하이픈 없이 01012345678도 가능)

- 이메일 또는 전화번호로 로그인 가능
- 아이디/비밀번호 불일치 시 에러 메시지 표시 확인
- '아이디 저장' 체크 후 로그인 → 재접속 시 아이디 자동 입력 확인
- 소셜 로그인 버튼(네이버/카카오/구글) 클릭 시 '추후 연동 예정' 알림 확인
- '회원가입' 링크 클릭 시 sc201_2로 이동

로그인 후 분기
  - 신체정보 미입력 상태 → sc202로 이동
  - 신체정보 입력 완료 상태 → sc301(대시보드)로 이동

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[회원가입, sc201_2]
입력 항목: 이메일, 닉네임, 비밀번호, 비밀번호 확인, 전화번호, 인증번호

유효성 검사 (실시간)
  - 이메일: 형식 오류 / 중복 시 에러 표시
  - 비밀번호: 8자 미만 시 에러 표시
  - 비밀번호 확인: 불일치 시 에러 표시

전화번호 인증
  - 전화번호 입력 후 '인증번호 전송' 클릭
  - 인증번호는 브라우저 개발자도구 콘솔(F12)에서 확인
  - 6자리 입력 시 일치 여부 실시간 확인

- 가입 완료 시 팝업('가입이 완료되었습니다! 환영합니다 [닉네임]님') 표시
- '시작하기' 클릭 시 sc202로 이동

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[신체정보 입력 1, sc202]
입력 항목: 성별, 생년월일(년/월/일), 키(cm), 현재 체중(kg)

- 모든 항목 입력 후 '다음 단계 →' 클릭 시 sc203으로 이동
- 생년월일 월(1~12), 일(1~31) 범위 외 입력 시 경고 확인

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[신체정보 입력 2, sc203]
입력 항목: 평소 활동량, 목표 감량(kg), 달성 기간

달성 기간 선택
  - 4주 / 8주 / 12주 / 16주 선택 가능
  - '기타' 선택 시 직접 입력 필드 표시 (1~52주)

BMI 표시
  - sc202 입력값 기반으로 현재 BMI 자동 계산 및 상태 표시
    (저체중 / 정상 / 과체중 / 비만)

목표 프리뷰
  - 목표 감량 + 기간 입력 시 '[현재]kg → [목표]kg | [기간] 동안 [감량]kg (주 Xkg)' 표시

과도한 목표 경고
  - 주 감량 1kg 초과 시 빨간 경고 박스 실시간 표시
  - '완료하기' 제출 시 confirm 팝업으로 재확인

- '← 이전' 클릭 시 sc202로 이동
- '완료하기' 클릭 시 sc302로 이동

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[AI 플랜 생성 로딩, sc302]
- sc203 완료 후 자동 진입
- 로딩 메시지 순환 확인 ('식단 패턴을 분석하고 있어요...' 등 1.8초마다 변경)
- 단계 표시 순서 확인 (신체 분석 → 플랜 생성 → 최종 검토)
- 약 4초 후 sc301(대시보드)로 자동 이동
- 좌측 사이드바 메뉴 정상 표시 확인

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[메인 대시보드, sc301]
- 로그인 후 또는 sc302 완료 후 진입
- 사이드바에 닉네임, 키, 성별, 현재/목표 체중 정상 표시 확인
- 목표 진행률 도넛 차트 표시 확인
- BMI 게이지 바늘 위치 및 기초대사량(BMR), 권장 칼로리(TDEE) 표시 확인
- 물 섭취 트래커: '+ 한 잔 마셨어요' / '초기화' 버튼 동작 확인
- 연속 기록(스트릭): 식단+운동 둘 다 체크한 날 기준으로 카운트 확인
- 체중 기록 입력 후 그래프 표시 확인

오늘 목표 체크
  - 식단 카드 하단 체크박스 → 체크 시 달성도 +1% 반영
  - 운동 카드 하단 체크박스 → 체크 시 달성도 +1% 반영
  - 둘 다 체크 시 '🎉 오늘 목표 달성!' 메시지 표시

달력
  - 월 이동 화살표(‹ ›) 동작 확인
  - 날짜 클릭 시 일정 입력 팝업 표시
  - 일정 저장 후 해당 날짜에 빨간 dot 표시 확인
  - 일정 삭제 확인

카드 클릭 이동
  - '오늘의 식단 →' 클릭 시 sc311 식단 탭으로 이동
  - '오늘의 운동 →' 클릭 시 sc311 운동 탭으로 이동

로고/로그아웃
  - 사이드바 로고(HealthDash) 클릭 시 sc101(랜딩)으로 이동
  - '로그아웃' 클릭 시 sc101로 이동

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[오늘의 식단/운동, sc311]
진입 경로
  - sc301 '오늘의 식단 →' 클릭 → 식단 탭으로 진입
  - sc301 '오늘의 운동 →' 클릭 → 운동 탭으로 진입
  - 좌측 메뉴 '오늘의 식단/운동' 클릭 → 기본 식단 탭으로 진입

식단 탭
  - 아침 / 점심 / 저녁 / 간식 항목 및 칼로리 표시 확인
  - 각 항목 아이콘이 음식 이름에 맞게 자동 매핑되는지 확인
    (예: 닭가슴살 → 🍗, 연어 → 🐟, 그릭요거트 → 🫙)
  - '📷 인증' 버튼 클릭 시 sc401로 이동 (현재 미구현)
  - 인증 완료 시 해당 칼로리가 상단 '인증 완료' 수치에 반영 확인
  - 새로고침 후 인증 상태 유지 확인

운동 탭
  - 유산소 / 근력 / 스트레칭 항목 및 소모 칼로리 표시 확인
  - 각 항목 아이콘이 운동 이름에 맞게 자동 매핑되는지 확인
    (예: 스쿼트 → 🏋️, 푸시업 → 💪, 걷기 → 🚶, 스트레칭 → 🧘)
  - 체크버튼 클릭 시 완료 처리 및 소모 칼로리 누적 확인
  - 달성률 바 업데이트 확인
  - 새로고침 후 체크 상태 유지 확인

AI 상담
  - 우측 상단 'AI 상담' 버튼 클릭 시 채팅 패널 슬라이드 오픈 확인
  - 로그아웃 버튼 위치가 채팅 패널 열기 전후 동일한지 확인
  - 메시지 입력 후 전송(Enter 또는 버튼) 시 AI 응답 확인
  - '×' 버튼으로 패널 닫기 확인
