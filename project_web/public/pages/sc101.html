FEATURES

건강 관리의 모든 것

AI가 분석하고 추천하는 완전한 건강 관리 솔루션. 식단부터 운동까지 하나의 플랫폼에서 관리하세요.

🥗
AI 식단 인증

음식 사진을 찍으면 AI가 자동으로 분석하고 오늘의 권장 식단과 일치하는지 확인해드립니다.

💪
맞춤형 운동 플랜

신체 정보와 목표를 바탕으로 AI가 개인화된 운동 프로그램을 생성하고 METs 기반으로 칼로리를 계산합니다.

📊
목표 진행률 추적

체중 변화 그래프와 달력으로 일별 인증 현황을 한눈에 파악하고 목표 달성까지 동기를 유지하세요.

🤖
AI 실시간 상담

건강 관련 궁금증이나 식단 변경이 필요할 때 AI와 실시간으로 대화하며 맞춤형 가이드를 받으세요.

📅
달력 일정 관리

월별 식단·운동 인증 현황을 달력 형태로 확인하고 특정 날짜의 상세 기록을 조회할 수 있습니다.

🔄
AI 재스케줄링

계획 미이행이 누적되면 AI가 자동으로 잔여 일정을 재계획하고 동기부여 메시지를 전송합니다.
